# Data Mining - Data Lake Assignment

## Dataset

Use:

dataset/sales.csv

## Task

Use Google Colab and Apache Spark.

Create a simple Data Lake structure:

Bronze Layer
- Store the raw dataset without modification.

Silver Layer
- Perform basic preprocessing using PySpark.
- Identify and handle data discrepancies.
- Save the processed dataset in the Silver layer.
